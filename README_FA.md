# رنو سیتی – پروژه آغازین اندروید

این پروژه یک نمونه اولیه اندروید با Kotlin و Jetpack Compose است.

## ساخت APK با GitHub Actions
1. فایل‌های این پوشه را در ریشه مخزن GitHub بارگذاری کنید.
2. از بخش Actions اجرای workflow با نام `Build Renocity Android APK` را بررسی کنید.
3. پس از موفقیت، در صفحه اجرای workflow بخش Artifacts فایل `renocity-debug-apk` را دریافت کنید.
4. فایل ZIP دریافت‌شده را باز کنید و `app-debug.apk` را روی گوشی نصب کنید.

## وضعیت
این فقط نسخه نمایشی اولیه است. هنوز API، پایگاه داده، پیامک، پرداخت، چت واقعی، پنل مدیریت و احراز هویت متصل نشده‌اند.
برای انتشار عمومی باید کلید امضای release، سیاست حریم خصوصی، تست امنیتی و تکمیل امکانات انجام شود.
